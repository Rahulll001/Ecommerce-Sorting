
# E-commerce Product Sorting

## Introduction
This project sorts e-commerce product prices
using the Divide and Conquer strategy.

## Objective
To arrange product prices in ascending order.

## Data Structure
Array (Python List)

## Algorithm
Merge Sort

## Input
[500, 200, 800, 100, 400]

## Output
[100, 200, 400, 500, 800]

## Time Complexity
O(n log n)

## Conclusion
Merge Sort efficiently sorts product prices
using the Divide and Conquer strategy.
